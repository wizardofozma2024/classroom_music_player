WHAT IT IS:
Instant shuffle of your ENTIRE song library! All 150+ songs loaded
and shuffled in one click.

WHERE STUDENTS SEE IT:
New button below "Request a Song":
[🔀 Shuffle All Songs] (orange-ish color)

HOW IT WORKS:
1. Click "🔀 Shuffle All Songs"
2. System loads ALL songs from your master database
3. Shuffles them randomly
4. Adds all to student's playlist
5. Starts playing automatically!
6. Notification: "🔀 Shuffled 150 songs from the library!"

PERFECT FOR:
• "I can't decide what to listen to!"
• Discovery mode - hear songs they forgot about
• Long work sessions
• Background music for projects
• Just want to be surprised!

TECHNICAL:
• Loads entire song database
• Randomizes order using Fisher-Yates shuffle
• Replaces current playlist with shuffled version
• Auto-plays first song
• Shows notification with song count
